# 创建新的 XLSX

用于从零创建普通数据表、分析结果、交互式报表或财务模型。先阅读 `excel-common.md`；涉及公式时同时读取 `excel-formulas.md`。

## 创建前规划

先定义：

- 工作表名称、顺序和用途；
- 输入、计算、汇总和说明区域；
- 字段类型、单位和必填约束；
- 哪些值是原始输入，哪些是公式或静态分析结果；
- 数字格式、筛选、冻结窗格、表格、数据验证和打印要求；
- 跨表引用和需要用户刷新计算的公式。

工作表名称不得超过 31 个字符，不能包含 `[]:*?/\\`，同一工作簿内不能重名。

## 公式与固定值

- 用户需要可交互模型或数据变化后自动更新时，派生值使用 Excel 公式。
- 用户需要审计快照、分析结论或固定导出时，可以写入已计算结果，并标明生成时间和来源。
- 原始输入和假设可以硬编码；不要把用户未提供的假设伪造成真实数据。
- 财务模型可按用户要求区分输入、同表公式、跨表引用和待审核假设；普通业务表不强制使用财务颜色惯例。

## 数据和格式

使用 `openpyxl.Workbook()` 创建新文件，并优先设置命名样式或复用样式对象：

- 文本保持文本；
- 数值保持数值；
- 日期写为 `date`/`datetime`；
- 百分比保存为小数并设置百分比格式；
- 年份使用不带千位分隔的格式；
- 货币符号和负数格式由用户指定；
- 列宽按内容设置合理上限，长文本使用自动换行；
- 标题、表头、正文和合计保持一致的视觉层级。

普通数据区域优先使用 Excel Table 或自动筛选，并按需要设置：

```python
worksheet.freeze_panes = "A2"
worksheet.auto_filter.ref = worksheet.dimensions
```

不要同时用自动筛选和 Table 表达两个相互冲突的范围。合并单元格只用于标题或明确版式，不用于普通数据表。

## 数据验证与公式输入安全

- 枚举、日期范围和数值范围使用数据验证。
- 验证提示和错误信息使用简体中文。
- 用户未要求公式时，以 `=`, `+`, `-`, `@` 开头的不可信字段按文本写入，避免公式注入。
- 不创建外部连接、DDE 或联网函数。

## 交付检查

1. 保存到不存在的新路径。
2. 重新打开并核对工作表、行列、数据类型、公式和格式。
3. 检查筛选、冻结窗格、表格、数据验证和命名区域。
4. 有公式时核对公式字符串和引用工作表。
5. 有公式但没有计算引擎时，说明公式缓存尚未刷新。
6. 没有兼容表格应用渲染时，不声称列宽、图表和打印版式已完全确认。
